# Triage labels

工程技能使用以下规范角色；右栏是本仓库 GitHub Issues 中使用的标签。

## 状态标签

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估。 |
| `needs-info` | `needs-info` | 等待报告者补充信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求充分，可交给 agent 实施。 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策。 |
| `wontfix` | `wontfix` | 不处理。 |

## 分类标签

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `bug` | `bug` | 已有行为不符合预期。 |
| `enhancement` | `enhancement` | 新功能或改进。 |

每个完成 triage 的 issue 使用一个分类标签和一个状态标签，可同时保留其他主题标签。已有多个状态标签时，先请维护者确认目标状态。

工程技能提及规范角色时，使用表中对应的 GitHub 标签；修改映射时同步检查 tracker 中是否存在对应标签。
