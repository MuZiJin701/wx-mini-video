# Domain docs

## 读取规则

- 根目录 `GLOSSARY.md`：本仓库领域术语的唯一来源。
- `docs/adr/`：涉及当前区域的决策记录，按编号或主题读取。
- `wx-mini-video-knowledge.md`：实现、配置、构建、排障与验收细节。

术语明确后即时更新 `GLOSSARY.md`。issue 标题、设计建议、假设、测试名称和代码标识使用术语表定义的名字，避免 `_Avoid_` 同义词；概念缺失时先判断是否误用领域语言，确有缺口再澄清并记录。提议与 ADR 冲突时，指出具体 ADR、冲突内容与重议理由。

## 布局与维护

单上下文仓库：根目录 `GLOSSARY.md`，`docs/adr/`（当前 0001–0013），`wx-mini-video-knowledge.md`；历史计划与已实现需求的背景放 `docs/archive/`。

`GLOSSARY.md` 只保存领域术语；实现细节、配置、规格和临时计划写入相应文档。只有决策难以逆转、缺少背景会令人意外且经过真实取舍时才新增 ADR；编号接续现有 ADR，替换已有决策时明确记录替代关系。
