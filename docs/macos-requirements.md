# macOS 版本需求

状态：2026-10-20 用户已确认完整需求。适配实现与真实 Mac 验收尚未开始，本文不表示已有 macOS 可用版本。分发取舍见 [ADR 0006](adr/0006-macos-portable-distribution.md)。

## 目标与支持范围

- 在 Mac 本机运行，嗅探同一台 Mac 上微信小程序的媒体，保留现有目标选择、小程序发现、图片、直链视频、直链音频和 m3u8 媒体下载流程。
- 首版面向普通用户公开发布，同时支持 Apple Silicon 和 Intel Mac。
- 首版系统目标为 macOS 13 及以上；微信优先支持发布验收时的官方最新稳定版，公开说明实际通过验收的系统、微信版本和处理器组合。目标范围不表示所有组合均已验证。
- 继续按请求来源 AppID 严格匹配目标 AppID，来源缺失时仍过滤，不因 macOS 适配放宽范围。见 [ADR 0003](adr/0003-target-appid-filtering.md)。

## 分发与启动

- 两种处理器使用同一个便携 ZIP；用户完整解压后双击入口，打开终端 TUI，无需安装 Go 或输入启动命令，提供中文说明。
- 接受首次运行或移动便携文件夹后，按引导确认解压目录或移动应用；日常使用仍双击启动。具体入口及引导步骤须先用 Mac 真机验证。
- 正式公开发布必须完成开发者签名与 Apple 公证，遵循 [Apple Developer ID 站外分发流程](https://developer.apple.com/developer-id/)。不将关闭系统安全保护作为默认使用步骤。

## 文件与升级

- 默认媒体目录为完整解压后的便携应用目录下的 `downloads/`，与 Windows 当前布局一致；自动创建目录，按 `o` 打开。
- 配置及其他运行数据沿用便携布局。升级保留配置和 `downloads/`，不向应用包内部写入下载数据。
- 本工具生成的独立根证书与私钥保存在本机用户的受限目录中，不随压缩包或媒体目录移动，升级及移动程序不重新生成。遵循 [ADR 0005](adr/0005-local-ca-lifecycle.md) 的每用户本地独立证书原则；macOS 应使用持久目录，避免缓存清理造成换证书。
- 发布包不内置 ffmpeg；首次下载 m3u8 时自动获取与处理器匹配的固定版本并校验，保留手动指定路径。沿用 [ADR 0001](adr/0001-managed-ffmpeg.md) 的受管依赖原则。

## 授权与网络

- 首次使用通过 macOS 系统提示授权设置代理、安装并信任本机独立根证书；日常 TUI 以普通用户运行。
- 退出自动恢复本程序改动过的原代理设置；根证书信任持续保留，并提供卸载说明。
- 发现已有代理或 VPN 配置冲突时提示处理；运行中切换 Wi-Fi/有线网络时暂停嗅探并提示重新启动代理。

## 先行验证与发布门槛

用户表示可安排相关资源；实际测试机型、系统、微信版本及签名条件在执行前核实。先验证两个会影响方案成立的前提，再展开完整适配：

1. 验证真实下载的签名、公证 ZIP 经完整解压及允许的一次性引导后，能够双击启动，并准确读写原便携应用目录的配置与 `downloads/`；移动目录后同样验证。
2. 验证 Mac 微信请求经过本机 HTTPS 代理、接受独立根证书，并提供严格匹配目标 AppID 所需的请求来源信息。

前提通过后，两种架构分别完成真实微信、图片、直链视频、直链音频、m3u8、首次授权、双击启动、代理冲突、网络切换及代理恢复验收，才能正式发布。保存实际通过的版本组合；构建和自动化测试不能替代真实微信验收。

若验证无法满足上述要求，重新讨论受影响的需求或技术方案，不静默更改媒体保存位置或放宽来源过滤。

## 代码现状与技术风险

- 系统代理、证书信任库和部分进程操作目前只有 Windows 实现；已进行一次 `darwin/arm64`、`CGO_ENABLED=0` 编译探查，因缺少平台函数失败，未生成 macOS 程序。
- TUI、目标选择、媒体识别及主要下载流程可作为复用基础；受管 ffmpeg 的 macOS 资源、校验及执行权限仍需适配。
- [Apple App Translocation 说明](https://developer.apple.com/forums/thread/724969)指出，下载的应用可能从随机路径运行，通过应用路径寻找包外相邻文件可能失败，也没有受支持的方法取回原始应用路径。[Apple Gatekeeper 排障说明](https://developer.apple.com/forums/thread/706379)另记录了独立命令行工具经 Finder 双击被拦截的问题。这些官方记录说明需要实际分发验证，不能推断所有现行系统都必然出现相同行为。
- 签名、公证、增加双击脚本或构建成功，都不能单独证明便携启动和微信嗅探可用。
