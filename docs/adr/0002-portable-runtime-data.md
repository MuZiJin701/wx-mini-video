# 默认使用便携应用目录中的运行时数据

分发 zip 只包含可执行文件、配置模板和说明；用户解压后，空 `download.dir` 默认解析为便携应用目录下的 `downloads/`，其中保存媒体、缓存、日志、证书和受管 ffmpeg。选择该目录而非当前工作目录或用户公共下载目录，以保持整套应用可携带并避免把运行时数据写入与程序无关的位置。

切换目标 AppID 或替换新版 exe 时保留这些运行时文件；目标切换只清空当前候选及进度。直链音频共用已有下载目录、部分下载和历史记录。

显式设置 `WX_MINI_VIDEO_CONFIG` 时，空 `download.dir` 使用该配置文件目录下的 `downloads/`；普通发布包的配置与 exe 同目录，因此默认保持便携布局。

2026-10-20 已确认、待实现的私钥存储例外见 [ADR 0005](0005-local-ca-lifecycle.md)：本工具生成的独立根证书与私钥改存本机用户目录，不随便携下载目录移动；媒体等既有数据布局保持不变。
