# macOS 保留便携分发与下载目录

状态：2026-10-20 用户已确认的需求决策，已补本地适配；真实 Mac 验收、签名和公证尚未完成。

macOS 首版采用同时支持 Apple Silicon 与 Intel 的便携 ZIP，延续终端 TUI，媒体默认保存到完整解压后的便携应用目录下的 `downloads/`。用户明确要求保持 Windows 版本的文件组织，因此选择便携分发，替代讨论初期的 DMG 安装方案；延续 [ADR 0002](0002-portable-runtime-data.md) 的布局及 [ADR 0005](0005-local-ca-lifecycle.md) 的本机私钥例外。

这一选择需要处理 macOS 首次运行保护对双击入口及相邻目录定位的影响。用户接受首次运行或移动目录后的一次性引导，以保留日常双击和便携目录体验；正式发布仍以开发者签名、Apple 公证和双架构真实微信验收为门槛。启动及目录定位方案须先验证，不能仅凭签名或公证结果宣称可用。

完整需求和先行验证项见 [macOS 版本需求](../macos-requirements.md)。

用户后续明确当前没有 Mac 环境，要求先完成本地适配、由用户后续验证，取代“通过先行真机验证后再展开完整适配”的执行顺序；不改变正式公开发布须通过签名、公证和双架构验收的门槛。

2026-10-20 用户要求 Windows 与 macOS 包在最新 v0.1.8 Release 并列提供。发布入口合并，平台验收状态、实际构建提交和附件校验值分别记录；Mac 未签名、未公证和未真机验收的状态保留。
