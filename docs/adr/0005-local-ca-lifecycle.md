# 默认使用每用户本地独立根证书与私钥

状态：2026-10-20 用户已确认决策，尚未实现。当前程序仍使用原有证书加载与共享证书回退机制。

默认在首次启动代理前，为当前 Windows 用户在本机生成独立根证书与私钥，并在受限访问的用户目录中保存、持续复用。升级程序或移动 exe 不更换证书；更换电脑或 Windows 用户后重新生成并安装信任。相较于共享证书或随便携目录复制私钥，这一方案接受换电脑后重新建立信任的成本，避免公开或随包传播私钥；Echo 代理保持不变。

显式配置的 `cert.file` 与 `cert.key` 优先，否则使用本工具生成的证书对，不再自动借用 mitmproxy 证书；需要复用其他工具的证书时可显式配置。配置不完整、证书或私钥无效，以及证书安装、保存失败时停止启动代理，不静默回退到其他证书。

迁移时检测旧共享根证书，在说明可能影响其他依赖该证书的代理工具后，经用户明确确认，按固定指纹 `D70CD039051F77C30673B8209FC15EFA650ED52C` 精确删除，不按名称批量删除。取消或删除失败时保留未清理提示，不宣称旧信任风险已经消除；安装新证书不会自动撤销旧证书的信任。

本决策为 [ADR 0002](0002-portable-runtime-data.md) 的便携数据布局增加私钥例外：媒体与其他既有运行时数据继续采用原布局，本工具生成的私钥不放入便携下载目录，不加入仓库、发布包或日志。
