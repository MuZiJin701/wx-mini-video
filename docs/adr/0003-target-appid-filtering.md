# 以明确的请求来源严格限定目标小程序

状态：已由 [ADR 0008](0008-target-attribution.md) 修订（2026-10-25）：目标归属仍保持严格匹配，但来源未知的媒体进入独立的未归属列表，不再在分类前直接丢弃。以下保留原始决策背景。

AppID 从会话标签改为目标范围：仅接受格式明确的微信小程序 Referer，并完整匹配目标 AppID；已匹配 JSON 接口可提供图片、直链视频和直链音频候选，独立来源未知的媒体不放行。用户选择优先保持列表清晰，接受因此漏掉部分媒体，而不通过共享 CDN 域名或跨请求 URL 关联扩大范围；发现阶段只登记小程序标识，选择后重新加载媒体，目标代次变化使在途旧响应失效。

加入直链音频后，直接响应和 JSON 音频候选沿用同一来源准入规则；音频支持不会扩大来源范围。
