# 默认使用受管 ffmpeg

状态：已由 [ADR 0007](0007-bundled-ffmpeg.md) 修订（2026-10-25）。默认分发改为随完整包提供 ffmpeg，受管下载降为完整包缺失或损坏时的兜底；以下保留原始决策背景。

发布包不内置 ffmpeg。显式配置的 `download.ffmpeg` 优先；否则工具在用户首次下载 m3u8 媒体时使用下载目录中的受管 ffmpeg，并在缺失时下载它，而不是静默使用系统 PATH 中的任意 ffmpeg。受管下载固定版本并校验 SHA-256；升级时显式更新版本和摘要。这样牺牲首次 m3u8 下载的等待时间，换取可识别、可复现的运行时依赖。

图片、直链视频和直链音频直接保存原文件，不触发 ffmpeg 准备；音频 m3u8 仍走既有播放列表流程并输出 mp4，不新增音频转码路径。
