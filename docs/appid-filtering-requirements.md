# AppID 过滤需求

状态：逐项决策已确认，等待用户核对汇总；尚未实现。术语以根目录 `GLOSSARY.md` 为准。

## 已确认

- AppID 必须用于限定目标小程序的候选资源，不能只作为会话标签。
- 明确属于其他小程序的资源不进入目标列表。
- 无法确认属于目标小程序的资源不进入目标列表，接受因此可能漏掉部分目标媒体。
- 保留手动输入 AppID，并提供小程序发现入口，让用户选择目标。
- 请求来源明确包含目标 AppID 时接收其中的媒体；已匹配目标 AppID 的 JSON 接口允许提取图片与直链视频。
- 无法识别来源的独立媒体请求排除，不因共同 CDN 域名放行；首版不增加跨请求媒体 URL 关联。
- 发现列表展示小程序名称与 AppID；名称缺失时显示“名称未识别”，允许用户补填。名称只用于辨认，过滤依据始终是 AppID。
- 一次只嗅探一个目标，允许返回目标选择界面切换；切换清空旧目标的候选列表和进度，保留已下载文件。
- 下载正在进行时暂不允许切换目标。
- 小程序发现期间只收集小程序标识，不收集媒体或生成媒体缓存；由用户明确选择目标，即使只发现一个也不自动选择。
- 选定目标后提示用户重新打开图片或播放视频，再开始媒体嗅探；手动输入 AppID 后直接进入目标嗅探。

## 用户流程

1. 启动界面提供“输入 AppID”和“小程序发现”两种入口。
2. 手动输入入口接受 AppID 和可选名称；小程序发现入口提示用户在 PC 微信中打开目标小程序，持续列出发现的小程序。
3. 发现列表展示名称与 AppID；可靠名称信息不可用时显示“名称未识别”，允许用户补填后选择。
4. 用户选定目标后才收集候选资源，并提示重新加载目标媒体。
5. 返回选择界面可切换目标；下载进行中给出说明，暂不允许切换。

输入界面与 README 补充 AppID 查找说明。未发现目标时提示重新打开小程序或改用手动输入；目标列表没有媒体时提示重新加载目标内容，并说明严格过滤可能排除无法确认来源的资源。

## 过滤边界

- 首版从可信格式的小程序请求来源信息解析请求来源 AppID，与目标 AppID 做完整匹配；不能在任意 URL、请求头或响应文本中模糊搜索目标 AppID 后放行。
- 统一覆盖图片、直链视频、m3u8 响应，以及 JSON 中提取候选的入口。
- 已匹配目标的 JSON 接口允许提取图片与直链视频；继续维持 JSON 中 m3u8 链接不直接进入列表的现有范围。
- 范围判断发生在媒体读取、远程回补和缓存之前，拒绝的候选不产生媒体缓存或回补请求。
- 过滤限定候选收集，不阻断正常网络请求。下载已准入的 m3u8 时，沿用其播放列表和依赖的现有下载流程。
- 目标切换清空旧目标候选与进度；保留已下载文件、历史、部分下载文件和已有缓存。重新选择目标后重新加载媒体。
- 名称只用于显示；不能根据名称、共享 CDN 域名或用户填写的会话标签证明请求归属。

## 验收规则

| 场景 | 预期结果 |
| --- | --- |
| 请求来源 AppID 等于目标 AppID，响应为支持的图片、直链视频或 m3u8 | 收集候选，m3u8 按现有流程缓存 |
| 请求来源 AppID 明确属于其他小程序 | 不收集候选，不产生媒体缓存或回补请求 |
| 请求来源 AppID 缺失、不可解析，或来源信息中仅出现相似 AppID | 不收集候选，不产生媒体缓存或回补请求 |
| 与目标共用 CDN 域名，但没有匹配的请求来源 AppID | 不收集候选 |
| 已匹配目标的 JSON 接口返回图片、直链视频链接 | 收集这些候选，并保留接口来源信息 |
| JSON 中出现 m3u8 链接 | 继续跳过；待实际观察到匹配来源的 m3u8 响应再收集 |
| 处于小程序发现阶段，尚未选择目标 | 可发现 AppID，不收集媒体或生成媒体缓存 |
| 只发现一个小程序 | 仍等待用户选择 |
| 名称缺失 | 显示“名称未识别”和 AppID，允许补填与选择 |
| 手动输入 AppID | 使用相同过滤规则，直接进入目标嗅探 |
| 切换目标 | 当前列表和进度清空，新媒体按新目标过滤；本地文件保留 |
| 下载进行中尝试切换目标 | 给出说明，目标保持不变，下载继续 |
| 请求被候选过滤规则排除 | 正常网络转发继续 |

实现后运行项目规定的 `go test -count=1 ./...` 与 `go vet ./...`，并为以上非平凡路径保留最小回归检查。真实 PC 微信验收须另外确认请求来源 AppID 的覆盖情况，不能以模拟测试代替。

## 已核对的现状

- 当前实现将识别到的候选资源统一标记为用户输入的 AppID，没有匹配请求来源。
- 代理能观察请求 URL 和请求头，当前没有微信窗口或小程序运行实例信息。
- JSON 响应中提取的图片、直链视频候选继承接口请求信息；JSON 中的 m3u8 链接当前不直接加入列表。
- m3u8 响应可能在加入列表前产生播放列表缓存，因此范围判断需要发生在读取、回补或缓存媒体之前。
- 真实 PC 微信请求携带 AppID 来源信息的覆盖情况尚未验证。
- 当前名称来自用户填写；已核对的微信账号信息接口不返回名称，基本信息接口返回名称但需要凭证或授权，不能保证仅凭任意发现的 AppID 查询名称。

名称接口参考：

- [wx.getAccountInfoSync](https://developers.weixin.qq.com/miniprogram/dev/api/open-api/account-info/wx.getAccountInfoSync.html)
- [获取小程序基本信息](https://developers.weixin.qq.com/doc/oplatform/openApi/OpenApiDoc/miniprogram-management/basic-info-management/getAccountBasicInfo.html)

## 已知限制

- 严格过滤优先保持目标列表清晰，可能漏掉来源信息缺失的目标媒体。
- 小程序发现仅列出代理实际观察到的小程序，覆盖范围需要真实 PC 微信验证。
- 首版名称缺失时允许用户补填，不承诺任意 AppID 都能自动查询名称。
- 首版不增加跨请求媒体 URL 关联，也不依赖名称查询凭证或新授权流程。
